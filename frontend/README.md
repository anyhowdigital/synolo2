# Τιμολόγιο Cloud – Ηλεκτρονική Τιμολόγηση, CRM & ERP με myDATA

Web εφαρμογή (SaaS) ηλεκτρονικής τιμολόγησης για ελληνικές επιχειρήσεις, εναρμονισμένη με τα Ελληνικά Λογιστικά Πρότυπα (ν. 4308/2014) και τη διαβίβαση εσόδων στην πλατφόρμα **myDATA** της ΑΑΔΕ. Περιλαμβάνει λογαριασμούς χρηστών με ρόλους, συνδρομές με Stripe, CRM πελατών, προσφορές, δελτία αποστολής, επαναλαμβανόμενα παραστατικά, έξοδα προμηθευτών, αποθήκη, αναφορές ΦΠΑ/Ε3 και δημόσιο REST API με webhooks.

## Γρήγορη εκκίνηση

```bash
npm install
npm run dev
```

Η εφαρμογή τρέχει στο <http://localhost:4870>. Την πρώτη φορά δημιουργείται η βάση `data/timologio.db` (migrations από `drizzle/`) και γεμίζει με επιδεικτικά δεδομένα.

**Δοκιμαστικοί λογαριασμοί**

| Ρόλος | Email | Κωδικός |
| --- | --- | --- |
| Ιδιοκτήτης | `demo@timologio.gr` | `demo1234` |
| Λογιστής (μόνο ανάγνωση) | `logistis@timologio.gr` | `demo1234` |

Μπορείτε επίσης να κάνετε **Εγγραφή** και να δημιουργήσετε νέα επιχείρηση με 14 ημέρες δωρεάν δοκιμή.

Άλλες εντολές:

```bash
npm run build       # παραγωγικό build
npm run start       # εκτέλεση build στο :4870
npm run lint        # ESLint
npm run db:generate # νέο migration μετά από αλλαγές στο src/db/schema.ts
```

Αντιγράψτε το `.env.example` σε `.env` για SMTP, Stripe, CRON_SECRET, APP_URL και τα στοιχεία παρόχου `LEGAL_*`. **Όλα είναι προαιρετικά για τοπική δοκιμή**: χωρίς SMTP τα email καταγράφονται στο Outbox (Ρυθμίσεις → Email), χωρίς Stripe η αγορά πακέτου και η online πληρωμή τιμολογίου γίνονται με σαφώς σημασμένη τοπική προσομοίωση.

Τα επιδεικτικά δεδομένα (επιχείρηση, πελάτες, προμηθευτές) χρησιμοποιούν **πλασματικά ΑΦΜ** που περνούν τον έλεγχο modulo 11 (π.χ. 800000118) και δεν αντιστοιχούν σε πραγματικές επιχειρήσεις.

## Λειτουργίες

**Λογαριασμοί & ρόλοι**
- Εγγραφή / σύνδεση με email & κωδικό (scrypt), επαναφορά κωδικού, sessions σε βάση.
- Πολλές επιχειρήσεις ανά χρήστη (π.χ. λογιστής με πρόσβαση σε πολλούς πελάτες), εναλλαγή από το sidebar.
- Ρόλοι: **Ιδιοκτήτης** (όλα + χρέωση), **Διαχειριστής** (ρυθμίσεις, χρήστες), **Χρήστης** (έκδοση), **Λογιστής** (μόνο ανάγνωση & εξαγωγές). Προσκλήσεις με email.

**Τιμολόγηση**
- Τύποι myDATA: 1.1–1.3 (Πώλησης), 2.1–2.3 (Παροχής), 5.1/5.2 (Πιστωτικά), 11.1/11.2/11.4 (Λιανική), **9.3 Δελτίο Αποστολής** (σκοπός διακίνησης, όχημα, διεύθυνση παράδοσης) και **Προσφορές** (εκτός myDATA).
- Σειρές με ανεξάρτητη αρίθμηση – συνεχή ή με ετήσια επανεκκίνηση.
- Όλες οι κατηγορίες ΦΠΑ και αιτίες απαλλαγής, παρακρατήσεις, χαρτόσημο, εκπτώσεις, χαρακτηρισμοί εσόδων Ε3, ξένο νόμισμα με ισοτιμία.
- Πρόχειρο → έκδοση → διαβίβαση (χειροκίνητα ή **αυτόματα** με την έκδοση) → είσπραξη → ακύρωση. **Μαζική διαβίβαση** εκκρεμών.
- **PDF στον server** (@react-pdf) για email, δημόσιο σύνδεσμο και λήψη· **δίγλωσσο (EL/EN)** παραστατικό για πελάτες εξωτερικού· **κωδικός πληρωμής RF** (ISO 11649).
- **Ισοτιμίες ΕΚΤ** αυτόματα στο ξένο νόμισμα (Frankfurter, cache στη βάση).
- **Πιστωτικό από τιμολόγιο** με ένα κλικ, **αντιγραφή** παραστατικού, αναζήτηση/φίλτρα/σελιδοποίηση.
- **Μαζικές ενέργειες** στη λίστα (επιλογή με checkbox): διαβίβαση myDATA, αποστολή email, λήψη PDF σε ZIP, εξαγωγή CSV, διαγραφή προχείρων.
- **Ιστορικό & συνεργασία** ανά παραστατικό/πελάτη: ενοποιημένο χρονολόγιο ενεργειών και emails, εσωτερικές σημειώσεις ομάδας, **συνημμένα αρχεία** (PDF, εικόνες, Excel, Word, XML έως 4 MB – αποθηκεύονται στη βάση, οπότε δουλεύουν και σε serverless).
- **Αποστολή με email** (PDF + XML) και **δημόσιος σύνδεσμος** `/p/<token>` για τον πελάτη, με αποδοχή/απόρριψη προσφοράς και **online πληρωμή με κάρτα** (Stripe Checkout· η είσπραξη καταχωρείται αυτόματα ως POS/e-POS, προαιρετικά με Stripe Connect `acct_…` του συνδρομητή).
- **Προσφορές** → μετατροπή σε τιμολόγιο με διατήρηση σύνδεσης.
- **Επαναλαμβανόμενα παραστατικά** (εβδομαδιαία / μηνιαία / τριμηνιαία / ετήσια) με αυτόματη έκδοση, διαβίβαση και email.
- **Υπενθυμίσεις πληρωμής** σε ρυθμιζόμενες ημέρες μετά τη λήξη.
- Εκτυπώσιμο Α4 με λογότυπο, MARK, UID, Authentication Code και QR ΑΑΔΕ.

**myDATA (ΑΑΔΕ)**
- Πλήρης λίστα τύπων παραστατικών myDATA (1.x–17.x), υποκαταστήματα (branch), αυτοτιμολόγηση.
- XML `InvoicesDoc` κατά XSD v1.0, `SendInvoices`, `CancelInvoice`, `RequestDocs` (λήψη παραστατικών προμηθευτών), `SendExpensesClassification` (χαρακτηρισμοί εξόδων), `RequestTransmittedDocs` (συμφωνία κατάστασης), `RequestMyIncome` (σύγκριση εσόδων) – σελίδα **myDATA συμφωνία**.
- Περιβάλλοντα: Προσομοίωση (προεπιλογή, χωρίς κλήσεις), Δοκιμαστικό, Παραγωγή. Αποθήκευση πλήρους XML αιτήματος/απάντησης.

**Έξοδα & ΦΠΑ εισροών**
- Παραστατικά προμηθευτών χειροκίνητα ή με συγχρονισμό από myDATA, χαρακτηρισμοί εξόδων (`category2_x`, `E3_585_xxx`), εκπιπτόμενος / μη ΦΠΑ.
- Αναφορές: ΦΠΑ εκροών ανά συντελεστή, ΦΠΑ εισροών, **αποτέλεσμα ΦΠΑ περιόδου με κωδικούς Φ2** (301–387, 470–484), έσοδα ανά Ε3, ενηλικίωση απαιτήσεων, **Excel** πολλαπλών φύλλων, CSV.
- **Λογιστική γέφυρα ΕΛΠ**: ημερολόγιο άρθρων (χρέωση/πίστωση) με ρυθμιζόμενους κωδικούς λογαριασμών, σε CSV/Excel για το λογιστικό πρόγραμμα. **Καρτέλα πελάτη** (statement) εκτυπώσιμη και Excel.

**CRM & ERP-lite**
- Πελατολόγιο με στάδια πωλήσεων, ιστορικό επικοινωνίας, εργασίες, υπόλοιπα. **Αναζήτηση VIES** για αυτόματη συμπλήρωση στοιχείων από ΑΦΜ.
- Είδη/υπηρεσίες, απόθεμα με αυτόματη μείωση/επαναφορά, όριο επαναπαραγγελίας.
- **Ταμείο & Τράπεζες**: λογαριασμοί (τράπεζα, ταμείο, κάρτες) με υπόλοιπα και ledger, εισπράξεις/πληρωμές ανά λογαριασμό, μεταφορές, λοιπές κινήσεις (προμήθειες, τόκοι, αναλήψεις), **εισαγωγή extrait CSV** (αυτόματη αναγνώριση στηλών EL/EN, ποσά «1.234,56», Windows-1253, αποφυγή διπλών) και **αυτόματη συμφωνία** με καταχωρημένες εισπράξεις/πληρωμές ή δημιουργία νέων από ανοιχτά παραστατικά (ποσό + αριθμός/όνομα), με χειροκίνητη σύνδεση και προτάσεις για τις υπόλοιπες.
- **Πιστωτικά υπόλοιπα πελατών**: προκαταβολές (είσπραξη χωρίς παραστατικό, στο ταμείο/τράπεζα), εμπορικές πιστώσεις/διορθώσεις, επιστροφές χρημάτων και **συμψηφισμός** ανοιχτών τιμολογίων με πιστωτικά τιμολόγια ή προκαταβολές (από τη σελίδα πελάτη ή του παραστατικού), με σωστή απεικόνιση στην καρτέλα πελάτη, στο ταμείο και στο client portal.
- **Εισαγωγή CSV** πελατών και ειδών (αυτόματη αναγνώριση στηλών EL/EN, UTF-8 ή Windows-1253, προεπισκόπηση, σφάλματα ανά γραμμή, πρότυπα αρχεία).
- **Καθολική αναζήτηση** Ctrl/⌘+K (παραστατικά, πελάτες, ΑΦΜ, MARK, είδη, προμηθευτές, ενέργειες) και **σκούρο θέμα**.
- Dashboard με διάγραμμα 12μήνου (έσοδα, έξοδα, εισπράξεις), **λίστα πρώτων βημάτων** (setup checklist) για νέους συνδρομητές και ειδοποιήσεις που κρύβονται για την ημέρα.
- Φόρμες που **δεν χάνουν τα δεδομένα** σε σφάλμα επικύρωσης, έλεγχος ΑΦΜ (modulo 11) την ώρα της πληκτρολόγησης, εμφανείς κανόνες κωδικού.

**SaaS & χρέωση**
- Πακέτα Starter / Pro / Business (μηνιαία ή ετήσια), δοκιμή 14 ημερών, όρια παραστατικών/χρηστών ανά πακέτο που εφαρμόζονται κατά την έκδοση.
- **Stripe Checkout** + webhook (`/api/stripe/webhook`) + Customer Portal. Χωρίς Stripe: τοπική φόρμα προσομοίωσης (`4242…` επιτυχία, `…0002` απόρριψη).
- **Έλεγχος λειτουργιών ανά πακέτο** (αποθήκη, CRM, επαναλαμβανόμενα, Excel, myDATA συμφωνία, υποκαταστήματα, API, λογιστική γέφυρα) με ειδοποιήσεις αναβάθμισης.
- Ασφάλεια: επαλήθευση email, **2FA (TOTP)**, λίστα/ανάκληση συνδέσεων, **ιστορικό ενεργειών** (audit log) με χρήστη & IP.
- **Πλήρης εξαγωγή δεδομένων** (ZIP με JSON + CSV) από Ρυθμίσεις → Επιχείρηση.
- Σελίδες Όρων χρήσης και Πολιτικής απορρήτου με στοιχεία παρόχου από `LEGAL_*`.

**API & ενσωματώσεις**
- REST API v1 με κλειδιά `tc_live_…` (Ρυθμίσεις → API & Webhooks): `GET/POST /api/v1/invoices`, `GET/POST /api/v1/invoices/{id}` (issue / transmit / cancel / email), `/api/v1/customers`, `/api/v1/products`.
- Όριο αιτημάτων ανά κλειδί (`API_RATE_LIMIT`, προεπιλογή 120/λεπτό) με headers `X-RateLimit-*` και 429.
- Webhooks με υπογραφή HMAC-SHA256 (`X-TC-Signature`) για έκδοση, ακύρωση, διαβίβαση, είσπραξη, αποδοχή προσφοράς· **ουρά παραδόσεων με επαναπροσπάθειες** (1λ → 5λ → 30λ → 2ω → 12ω) και ιστορικό/χειροκίνητη επανάληψη στις Ρυθμίσεις.
- Cron endpoints: `GET /api/cron/recurring` (έκδοση επαναλαμβανόμενων), `GET /api/cron/reminders` (υπενθυμίσεις), `GET /api/cron/webhooks` (επαναπροσπάθειες webhooks) – προστατεύονται με `CRON_SECRET`.

## Σύνδεση με το myDATA

1. Στο myAADE → Εφαρμογές → myDATA → **Εγγραφή στο myDATA REST API** εκδίδετε `aade-user-id` και `subscription key` (χωριστά για δοκιμαστικό και παραγωγικό).
2. **Ρυθμίσεις → myDATA**: επιλέγετε περιβάλλον και εισάγετε τα κλειδιά.
3. Διαβίβαση από τη σελίδα του παραστατικού ή αυτόματα με την έκδοση (**Ρυθμίσεις → Τιμολόγηση**).

## Deploy στο Vercel

1. Κάντε import το GitHub repo στο Vercel (framework: Next.js – ανιχνεύεται αυτόματα, υπάρχει `vercel.json` με cron jobs και region `fra1`).
2. Environment variables (Project → Settings → Environment Variables):
   - `APP_URL` = το domain του project (π.χ. `https://timologio.vercel.app`).
   - `CRON_SECRET` = τυχαίο string· το Vercel Cron το στέλνει αυτόματα ως `Authorization: Bearer`.
   - **Βάση δεδομένων (υποχρεωτική σε serverless):** είτε Vercel → Storage → Turso (ορίζει αυτόματα `TURSO_DATABASE_URL`/`TURSO_AUTH_TOKEN`), είτε `DATABASE_URL` + `DATABASE_AUTH_TOKEN` από [Turso](https://turso.tech) (`libsql://…`). Χωρίς βάση η εφαρμογή εμφανίζει τη σελίδα `/setup` με οδηγίες αντί να τρέξει – σε serverless κάθε instance θα είχε δική του εφήμερη SQLite και η εφαρμογή θα φαινόταν χαλασμένη.
   - `SEED_DEMO_DATA=true` **μόνο** αν θέλετε την επιδεικτική επιχείρηση (demo@timologio.gr / demo1234) και στην παραγωγή – ο κωδικός είναι δημόσιος, οπότε σε πραγματικό deployment αφήστε τη μεταβλητή κενή και δημιουργήστε λογαριασμό από το `/register`.
   - Προαιρετικά SMTP, Stripe, `LEGAL_*` (βλ. `.env.example`).
3. Deploy. Τα migrations εκτελούνται αυτόματα (με επαναλήψεις) στην πρώτη κλήση· το build δεν ακουμπά ποτέ τη βάση.
4. Έλεγχος: `GET /api/health` επιστρέφει `{"status":"ok","database":"ok"}` (HTTP 200) όταν η βάση είναι προσβάσιμη – χρήσιμο για uptime monitoring.

## Παραγωγική εγκατάσταση

- Ορίστε `APP_URL`, `CRON_SECRET`, SMTP και Stripe μεταβλητές (βλ. `.env.example`).
- Ρυθμίστε Stripe webhook στο `https://<domain>/api/stripe/webhook` για τα events `checkout.session.completed`, `customer.subscription.updated`, `customer.subscription.deleted`, `invoice.payment_failed`.
- Προγραμματίστε (cron) καθημερινή κλήση των `/api/cron/recurring` και `/api/cron/reminders` και ανά λίγα λεπτά του `/api/cron/webhooks`, με header `Authorization: Bearer $CRON_SECRET`.
- Ορίστε τα `LEGAL_*` (επωνυμία, ΑΦΜ, διεύθυνση, emails παρόχου) – χωρίς αυτά οι σελίδες Όρων/Απορρήτου δείχνουν placeholder.
- Για online πληρωμή τιμολογίων ο κάθε συνδρομητής μπορεί να δηλώσει Stripe Connect λογαριασμό (`acct_…`) στις Ρυθμίσεις → Τιμολόγηση ώστε τα ποσά να μεταφέρονται σε αυτόν.
- Για πολλαπλά instances χρησιμοποιήστε Turso/libSQL μέσω `DATABASE_URL` + `DATABASE_AUTH_TOKEN`.
